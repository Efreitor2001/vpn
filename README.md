# Warsaw single-server VPN

`main.py` объединяет панель, VLESS/WS-вход и прямой выход Xray на одном сервере.
Вторая нода и специальная маршрутизация не нужны.

## Environment

Скопируйте значения из `.env.example` в переменные проекта Amvera.
`ADMIN_USER` и `ADMIN_PASSWORD` нужно обязательно заменить.

## Persistence

Не очищайте `/data` при обновлениях. Основная база пользователей:
`/data/service/panel-db.json`.

На первом запуске актуальные 17 UUID автоматически добавляются как активные
пользователи без срока действия. Маркер миграции не позволяет вернуть удалённых
пользователей на следующих перезапусках.
