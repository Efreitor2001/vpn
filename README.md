# Warsaw single-server VPN

`main.py` объединяет панель, VLESS/WS-вход и прямой выход Xray на одном сервере.
Вторая нода и специальная маршрутизация не нужны.

## Environment

Скопируйте значения из `.env.example` в переменные проекта Amvera.
`ADMIN_USER` и `ADMIN_PASSWORD` нужно обязательно заменить.

## Persistence

Не очищайте `/data` при обновлениях. Основная база пользователей:
`/data/service/panel-db.json`.

Существующие пользователи в `/data/service/panel-db.json` сохраняются при
обновлениях и не перезаписываются из исходного кода. Для разового импорта в
новый том `/data` можно передать UUID через `XRAY_MIGRATED_CLIENT_UUIDS`
(значения через запятую), а затем удалить эту переменную. Не храните реальные
UUID в Git: это ключи доступа к VPN.

Если импорт не задан, первый запуск создаёт случайного базового пользователя,
ссылку которого можно получить в админ-панели.
